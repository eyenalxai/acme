# Domain

This file holds the project's ubiquitous language. It records the words that the code,
the UI and the people use for the things this app is about. Each entry has one term, its
definition and the words to avoid. Acme ships with no product domain, so this file starts
nearly empty. Replace the Notes example's language with the product's language as it
arrives.

## Language

**Note**:
A single record owned by one user: a title and a body. The starter wires this record
through contract → router → Drizzle → React Query, as the worked example of a persisted
resource.
_Avoid_: memo, entry, item
